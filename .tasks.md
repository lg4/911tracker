  real value ('light'|'dark'). Also add `color-scheme` CSS so native date-picker chrome matches, drop the

  ("Activity Map") divergence, add a `<noscript>` message (page is two grey bars without JS).

- **T19 — quick-window date drift (UTC vs local):** `daysAgo(n)` builds dates from
  `Date.now() - n*24h` then truncates via `toISOString().slice(0,10)`, i.e. a UTC-midnight anchor,
  while `/api/incidents` parses `?since&until` as `${date}T00:00:00Z` / `T23:59:59Z`. For US
  Eastern users, local late evening (e.g. 7pm EDT = midnight UTC) makes "Today" resolve to
  *tomorrow's* calendar day — the window shifts by up to a full day. Fix: compute the local
  calendar date (not UTC) for the button defaults and document that the API treats them as UTC
  midnights; or push tz-aware bounds down into the function.
- **T20 — CSV line-endings + serializer test:** `toCsv()` already RFC-4180-quotes every field
  (web/index.html), so the remaining gap is rows joining with LF (`\n`) where Excel/WPS expect CRLF
  before honoring in-field newlines, and there is no unit test covering the serializer. Switch to
  CRLF joins and add a Node unit test asserting quote-doubling + newline preservation.
- **T21 — map snaps to one area:** user reports the viewport is "too snappy" to a single region —
  likely fitBounds re-framing on every refresh (and/or heat-layer extent) yanking the view back from
  wherever the user panned/zoomed. Audit update()/renderHeat() for any setView/fitBounds calls and
  make framing initial-load-only (respect manual navigation thereafter); document in runbook.
- **T22 — filters leave an empty map until 'All' is deselected:** exclusive-select model means
  clicking a category chip isolates it, but users report the map appears empty until they deselect
  All or pick one/two filters — i.e. the isolate-vs-additive mental model isn't landing. Re-examine
  chip interaction + status copy so the first click visibly changes what's shown (see H6/H4 critique
  items); consider additive multi-select with explicit clear instead of exclusive select.
- **T23 — export buttons into a nav menu:** CSV export (and other non-primary actions) clutter the
  header; move them behind a nav/menu control per DESIGN.md chrome rules. Keep shareable-link
  affordance discoverable.
- **Light-mode basemap caveat (doc note):** dark mode is pure-CSS tile inversion on local OSM tiles;
  light mode serves the raw unstyled pyramid. Note in docs/runbook.md that light mode looks plainer
  than typical styled basemaps by design (keyless/offline constraint), not a rendering bug.
